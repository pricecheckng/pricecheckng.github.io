The safe way to send

  • Ask the receiver: "Which network exactly?" and write the answer down.
  • Choose the same network on your side when you send or withdraw.
  • Send a small test first, wait for it to arrive, then send the rest.
  • Copy the address with the copy button. Never type it by hand.
  • Check the first and last characters after you paste.
  • Check the network fee shown before you confirm. Fees change, and some networks cost more than others.

Common networks

  • TRC20 (Tron): address starts with T. Often used for USDT because fees are usually low.
  • ERC20 (Ethereum): address starts with 0x. Usually the most expensive network.
  • BEP20 (BNB Smart Chain): address also starts with 0x, so it looks the same as ERC20. This is why mix-ups happen.
  • Solana, Polygon, Arbitrum: also used. Polygon and Arbitrum use 0x addresses too.
  • Bitcoin, XRP, Litecoin, Dogecoin: each has its own network and address type. Send only the same coin to these addresses.
