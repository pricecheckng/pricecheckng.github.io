How to add it to your site

WordPress

Edit a page or post, add a Custom HTML block, paste the code, then Update. In the widget area, add a Custom HTML widget in the same way.

Blogger

Layout, Add a Gadget, HTML/JavaScript. Paste the second code (under "Code not showing on your site?") and save.

Wix, Squarespace, Shopify

Add an Embed code or Custom HTML element and paste the code. If it does not show, use the second code.

Plain HTML website

Paste the code in your page where the prices should appear, for example in the sidebar or under a heading.

Still not showing?

Try these, in order:

  1. Use the second code under "Code not showing on your site?".
  2. In WordPress, paste it in a Custom HTML block, not a normal text block.
  3. Save the page, then open it in a new browser tab. The editor preview sometimes does not show the prices.

Frequently asked questions

Is the crypto price widget free?

Yes. The widget is free for blogs and websites. It shows a small 'Live prices by PriceCheck NG' link at the bottom, and we ask you to keep it.

How do I add a live crypto price widget to WordPress?

Pick your coins on this page, copy the code, then in WordPress add a Custom HTML block and paste it in. Save the page and the prices appear.

Does the widget work on Blogger, Wix or Squarespace?

Yes. Use the main code first. If the prices do not show, use the second code under 'Code not showing on your site?', which works on Blogger and most free site builders.

Can I show prices in Naira or other currencies?

Yes. Choose any of 50 currencies, including Naira (NGN), US dollars, pounds, euros, Ghana cedis, Kenyan shillings and more.

How often do the prices update?

The widget refreshes by itself every 30 seconds. Prices for major coins are updated about every minute on our side.

Will the widget slow down my website?

No. It is a small frame that loads on its own and does not run heavy scripts on your page.

Good to know
