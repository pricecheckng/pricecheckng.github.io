Quick start


Send your key in the x-api-key header. All requests are GET and return JSON.


curl "https://inufnxvilubbsrcusakt.supabase.co/functions/v1/api/prices?symbols=btc,eth&currency=ngn" \
  -H "x-api-key: pcn_live_YOUR_KEY"


const r = await fetch("https://inufnxvilubbsrcusakt.supabase.co/functions/v1/api/prices?symbols=btc&currency=ngn", {
  headers: { "x-api-key": "pcn_live_YOUR_KEY" }
});
const { data } = await r.json();
console.log(data[0].price); // Bitcoin price in naira


Keep your key on your server. Do not put it in a public website or mobile app.



Endpoints


GET /prices


A list of coins, sorted by market cap rank.




ParameterDescription


symbolsComma-separated symbols or ids, for example btc,eth. Optional.


currencyusd (default), ngn or another supported currency.


limit1 to 250. Default 100.

      "price": 109734340.25, "change_24h_pct": 0.38,
      "volume_24h": 25589611576762.81, "rank": 1 }
  ]
}



GET /coin/{id}


One coin by id or symbol, for example /coin/bitcoin?currency=ngn.



GET /fx


Exchange rates against the US dollar, including the naira.



GET /market


Global market summary: total market cap, Bitcoin dominance, and the Fear and Greed index.

Each person gets one free key. Your monthly calls reset on the 1st of every month. Data refreshes about every 5 minutes, so polling more often than that does not give newer prices. Cache the result on your side.


Prices update about every 5 minutes. That suits portfolio trackers, alert bots, apps and slower trading bots. For high-speed trading, use your exchange's own API.



GET /usage


Shows how much of your monthly quota you have used. This call is free and does not count against your limit.

  "plan": "free",
  "monthly_limit": 10000,
  "monthly_used": 681,
